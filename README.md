# Personal Task Management App

A 3-tier Spring Boot backend application built for tracking tasks, users, and alert configurations.

## Features
- **Task Management**: Endpoints to create, view, and delete tasks.
- **User Management**: Simple account tracking.
- **Task Alerts**: System reminder triggers.

## How to Run Locally
1. Clone this repository.
2. Open the project in Eclipse.
3. Right-click `App.java` and select **Run As -> Java Application**.
4. Access the API endpoints at `http://localhost:8080/api/tasks`.
